# GreenCity Testing Automation

## Опис проєкту

Автоматизований набір UI-тестів для сторінки [GreenCity Events](https://www.greencity.cx.ua/#/greenCity/events).  
Побудовано з використанням **Selenium WebDriver**, **Pytest** та **Allure Report**,  
з дотриманням архітектури **Page Object Model (POM)** та **компонентного підходу**.

---

## Технічний стек

| Інструмент | Призначення |
|---|---|
| Python 3.14 | Мова програмування |
| Selenium WebDriver | Автоматизація браузера |
| Pytest | Фреймворк для тестування |
| Allure Report | Звітність по тестах |
| ChromeDriver | Драйвер браузера Chrome |

### Компонентний підхід
Повторювані елементи винесені в окремі класи компонентів, які наслідують BaseComponent:

- **`BaseComponent`** — базовий клас із методами `find()`, `find_all()`, `click()` з явними очікуваннями WebDriverWait
- **`Header`** — навігаційні посилання, кнопки входу/реєстрації
- **`FilterPanel`** — 4 випадаючі фільтри (час, місце, статус, тип), кнопка очищення
- **`EventCard`** — одна картка події: заголовок, дата,зображення, клік

## Тест-кейси

### TC1 — `test_open_event_type_filter_menu`
**Сценарій:** Меню фільтра відкривається коректно

**Що робить:**  
Відкриває сторінку подій, натискає на фільтр **"Тип події"** та перевіряє,  
що випадаюче меню з'являється і містить хоча б одну опцію.

---

### TC2 — `test_negative_filter`
**Сценарій:** Стан фільтрів за замовчуванням

**Що робить:**  
Відкриває сторінку подій **без жодної взаємодії з фільтрами** та перевіряє,  
що чіп **"Економічний"** відсутній на сторінці за замовчуванням.

---

### TC3 — `test_select_all_event_types`
**Сценарій:** Вибір усіх типів подій

**Що робить:**  
Відкриває сторінку подій, відкриває фільтр **"Тип події"**,  
натискає **"Всі типи"** та перевіряє:
1. Список опцій видимий і заповнений
2. Опція "Всі типи" присутня в списку
3. У списку щонайменше 4 опції (Всі типи, Економічний, Соціальний, Екологічний)

**Перевірки:**
- `len(options) > 0` — опції завантажились
- `"Всі типи" in option_texts` — опція "Всі типи" існує
- `len(options) >= 4` — всі типи подій присутні
